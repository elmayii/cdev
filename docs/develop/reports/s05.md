# Sprint 05 report — Open-source readiness

*Contract delta for Sprint 06 (public README): the repository's public shell is in place.*

- **Branches:** `main` default in both repos (renamed via API, GitHub redirects). Protected:
  PR required for others, no force pushes, no deletions, conversations resolved —
  `enforce_admins` off so the owner's direct-commit convention (this repo's recorded override)
  keeps working; proven by every batch push this sprint.

  strategy topics, wiki off, **Discussions on**. Marketplace repo described and tagged too.

  strategy §13 fields) / config → Discussions, plus the PR template with the evidence

  `plugin.json`; notes cover what CDev is, what ships, the binding, install, limitations,
  what is experimental.
