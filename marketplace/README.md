# cdev-marketplace

Claude Code plugin marketplace serving the [CDev](https://github.com/elmayii/cdev) plugin.

## Install

```
/plugin marketplace add elmayii/cdev-marketplace
/plugin install cdev@cdev-marketplace
```

Skills install namespaced: `/cdev:cdev`, `/cdev:bootstrap`, `/cdev:cdev-planner`,
`/cdev:ockham`, `/cdev:bootstrap-monorepo`, `/cdev:cdev-monorepo`,
`/cdev:cdev-monorepo-planner`.
